## Reproduce

Extract the user-provided R27 prose into `.tmp/numerology-r28/R27-EDITORIAL.json` as recorded in the handoff preparation. Compile the review entry point with the repository's existing esbuild, then:

```powershell
node .tmp/numerology-r28/build.mjs --run
node .tmp/numerology-r28/build.mjs --run --pdf
node .tmp/numerology-r28/check.mjs
node .tmp/numerology-r28/delivery-qa.mjs
```

The PDF command needs normal local browser execution approval. `pdf_qa.py` reopens the generated files, checks 33 A4 pages and complete text, and rasterizes actual PDFs. HTML and SVG previews cannot satisfy PDF acceptance. No global `npm run check` is run in this round, per the user's execution scope.
