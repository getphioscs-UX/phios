# WORLD-R3-INFORMATION-ARCHITECTURE · Gate 2

Status: DESIGN_CANDIDATE_READY_FOR_HUMAN_REVIEW. Gate1 HUMAN_ACCEPTED; Gate2 not yet Human ACCEPTed; Gate3 NOT_AUTHORIZED. This is a self-contained design artifact, not a second product runtime or registry.

## Shared architecture, both viewports

World → one public question input → six question groups → one scoped answer or explicit coverage gap → evidence/interpretation/visual/impact/limits → relevant reading, compare and follow-up. A volume is never the first required choice.

Six groups: cost of living; work & industry; people & care; resources & infrastructure; places & change; the world & me. Ten named questions remain represented; three have complete design pages, the remaining seven have honest gap states. No semantic answer is invented for a non-example input.

Home uses one title/purpose, one search, one six-group list and the existing three reading modes. Country/year refinements appear in an answer, not as a second first-screen filter bank. Source/legacy entry remains a quiet link to existing R2. Desktop3 columns/mobile2 columns use identical records and handlers.

Answer priority: exact question/type → region/year and retrieval status → direct bounded answer → three reading perspectives → supported source definitions and explicit missing data → mechanism → meaningful visual → impacts → limits → source-specific next reading. Desktop has a sticky contents rail; mobile collapses the same contents element. Direct answer is ahead of scale explanations and expanded navigation on both layouts. No empty answer cards or numeric placeholder charts.

## Complete representative pages

- cost: Malaysia example scope, selected year, supported CPI definition, missing annual CPI/income evidence, mechanism diagram and household limits. General explanation is not a regional annual diagnosis.
- compare: Malaysia ×Vietnam, selected year, industry definition, three aligned evidence dimensions, reused R2 location geometry, no values/rankings where data are missing. Complete evidence-gap answer page, not a completed empirical comparison.
- personal: public interpretation + voluntary self-reports + next verification question. No account/Profile/PHI Configuration data read or automatic personal conclusion. Existing personal entries are separate optional links.

## State and interaction

Public query, locale, view, example ID, region, selected year and reading mode are encoded in the artifact URL and survive Back/reload. Free-text input outside the curated examples remains itself in a gap state. Country/place/topic input is illustrated by this single input; a broad geocoder, live search and natural-language retrieval are NOT implemented. Mode switching changes the reading lens and explanation, not the available evidence, and preserves the same question; separate production retrieval per mode remains Gate3 scope.

Private input is opt-in, memory-only, outside the public URL and both browser storage areas. Clear, refresh or a change of year/source context removes it. User text is escaped. No API, model, consent ledger, account write or external message exists in the prototype.

## Reuse decisions

Reuse R2 public-state concepts, three modes, palette and real geometry; preserve existing World/Search/Ask, canonical book projection and accepted source readers for future minimal integration. Five existing published bilingual readings are bound to their indexed hashes and versions, mainly BookVI with relevant BookI/II/IV explanations. No second platform asset registry is introduced: SOURCE-BINDINGS.json is a design receipt only.

The existing Atlas R2 objects are retained. No arbitrary civilization image is forced into a current-data answer. Some book-figure variants (such as 7B/13F) still have editorial-review-pending metadata, so this design does not promote them to accepted illustrations. The comparison map directly reuses the existing geometry; conceptual flows are HTML presentation sketches, not new canonical diagrams or R2 assets. BookV/VI production Atlas relationships remain available through the existing R2 product; widening diagram consumers waits for Gate3 and explicit relevance.

## Unresolved before production

Human design acceptance; licensed/defined topic observations and evidence refresh policy; real answer retrieval and claim-level support; existing Ask context repair; owner integration and current deployed topology. The design does not close Gate1 runtime/data gaps.
