R1-W8A-P2-P2A｜MOOMOO PKCE AUTH HELPER

Client Registration → PKCE S256 → Browser Authorization → Loopback Callback → In-memory Token → Governed Live Import

Security boundary: client_id may be cached locally; registration token, auth code, verifier, access token and refresh token are never persisted or printed.

One command

npm run moomoo:pkce-live-import

The helper opens the Moomoo authorization page and continues automatically after the localhost callback.

Callback

http://localhost:60355/callback

Bound only to 127.0.0.1 and guarded by OAuth state validation.

After authorization

The access token stays in process memory and is passed only to run-moomoo-first-live-import.mjs through the child environment. The first live capability remains HISTORY_KLINE only.
