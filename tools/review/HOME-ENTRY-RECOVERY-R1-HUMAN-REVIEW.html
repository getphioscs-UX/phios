  • PHIOS是什么 / What is PHIOS? → PLATFORM_INTRODUCTION → 现有 About 的 #how，以及 Knowledge / My Reality 真实入口。
  • 人为什么不快乐 → KNOWLEDGE_BASIC → KNOWLEDGE_SOURCE_INSUFFICIENT → 针对“不快乐”的概念／一般原因／具体情境澄清。

  • NO_MATCH、NEEDS_CLARIFICATION、KNOWLEDGE_SOURCE_INSUFFICIENT、INDEX_LOADING_FAILED、SERVICE_FAILURE 分开显示；后两项可实际重试。

实现与复用

品牌及一般解释意图由公共 router 分类；ENTRY API 直接复用 handlePublicKnowledgeRequest 的公开索引、来源与版本，不建立第二套检索库，不进入 provider 编排。只在 exact/strong 覆盖且存在来源正文时显示知识结果。安全照护、明确预约／订单帮助及原有付费 Ask 分支保留。

结果移到真实首页表单后方、共用同一容器。紧凑深色卡片只保留一个主要动作；移除重复失败说明及固定账户／报告链接。首页、Header、Ask ENTRY 均复用同一结果组件与重试回调。
