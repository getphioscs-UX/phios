# R1.2 shared release contract — existing owners only

Status: REVIEW PROPOSAL, no runtime/registry/price/entitlement change. This is an evidence contract for the existing pipeline, not a second production engine. Each report retains its own page plan, chapter depth, diagram grammar, language policy and admitted inputs.

`Source Admitted → Calculation Validated → Narrative Accepted → Visual Bound → Publication Fit → Q87 Verified → Human ACCEPT → Commercial Delivery Admission`

| Gate | Exact required evidence | Existing owner / boundary |
|---|---|---|
| Source Admitted | Source version, sourceRef/claim scope, digest and owner decision. A visual-only ACCEPT never admits a manuscript or method meaning. | Each native method's admitted source/accepted-copy registry; `content/reports/method-publication-profiles-v1.json` references those owners. |
| Calculation Validated | Immutable Subject/input snapshot + time/place policy + native calculation identity. Derived diagrams and prose must share its digest. For Profile use admitted evidence instead of fabricated method calculation; HD retains authorised external chart confirmation. | Native calculation adapter; `functions/account/canonical-person-store.js`; existing Subject/Consent owners. |
| Narrative Accepted | Exact manuscript/source spans, matching subject and language, applicable conditional modules and explicit unavailable layers. Frozen accepted text is reused, not regenerated. New prose/interpretation requires separate source/owner admission. | Existing Deep Manuscript/native narrative owners, never a new generic authoring runtime. |
| Visual Bound | Original R2 object/version/SHA/dimensions; diagram source semantics and functional-framework versus established-structure scope; actual final page map. | Existing R2 visual registry/native editorial owners; original WebP unchanged. |
| Publication Fit | Actual full PDF and render IR digests, complete source coverage, typography/overflow/occlusion, page boxes, native diagrams, selectable dynamic text, real links/bookmarks. No shared page/chapter/chart count. | Existing Shared Print Shell and per-method renderer/fit owners. HD keeps ReportLab; Financial Planning keeps its independent bilingual core/appendix owner. |
| Q87 Verified | Exact final sealed PDF input/output SHA, page/box/source-text/font/bookmark/link/metadata parity, image dimensions/alpha policy, all-page visual deltas, human print-quality decision. Historical synthetic candidates prove only their exact bytes. | Existing `tools/review/report-storage-optimization-r1/optimize.py`; no second compressor, no bulk historical recompression. A source with no suitable images can retain lossless bytes with an explicit receipt. |
| Human ACCEPT | Named owner decision tied to exact publication/manuscript/visual/rendition digests and scope. Technical PASS and seeded QA never set this flag. Source ACCEPT is preserved independently of new publication decisions. | Unique existing Master / method acceptance receipts. Model cannot grant acceptance. |
| Commercial Delivery Admission | Current method P8 and lifecycle admission; authorised Subject/consent/order/entitlement; approved commercial watermark; final bytes stored privately with SHA; account PDF MIME/attachment/identity/permissions; exact-byte cold reopen/redownload; revoke/refund and historical download preservation. | Existing method adapter, `paid-report-delivery-core.js`, `customer-report-artifact.js`, `customer-artifact-store.js`, Account material owners and `PRIVATE_REPORTS`. Financial stays under its existing independent business owner. |

Canonical publication record: retain existing record identity, immutable Subject/input/native snapshot, manuscript, Publication IR, accepted source/visual/font/renderer versions, approved watermark policy, source PDF SHA, rendition profile/output SHA and byte length, private object reference, entitlement/consent scope and issuance/revocation history. Extend existing record fields only where needed; no replacement report database.

Issue once after all gates. Redownload reads the exact issued artifact and checks current access/revocation; it never calls a narrative provider, recalculates the manuscript, regenerates a PDF or creates another charge. Preserve historical downloads and their original digests. A new approved rendition is an explicit immutable derivative, not silent replacement.

R1.2 changes no production configuration, store, D1/R2 object, Stripe contract, or shared registry admission. Commercial watermark and final issuance remain separate owner decisions. Live customer, sandbox, local seeded QA and offline replay are separate evidence classes.
