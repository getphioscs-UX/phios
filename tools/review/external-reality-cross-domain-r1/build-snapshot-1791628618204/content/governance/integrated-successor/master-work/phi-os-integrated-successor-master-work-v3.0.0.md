## CX-R9R2-W2｜Ask Drawer + Explicit Progressive Context Selector — UPGRADED


```text
Knowledge = default public context
Personal / Relationship / Profile context = explicit opt-in
Protected context availability = server / product authority controlled
Browser contextRef alone = never authorization
No silent account-wide context sweep
Unavailable context = not presented as usable
Person B / Relationship = participant + case scope shown before use

```

This step supersedes the earlier interpretation that all context controls must be fully expanded before every submit. It preserves CX-R9-R2 consent and provenance requirements while becoming compatible with CX-R31 Progressive Context.
