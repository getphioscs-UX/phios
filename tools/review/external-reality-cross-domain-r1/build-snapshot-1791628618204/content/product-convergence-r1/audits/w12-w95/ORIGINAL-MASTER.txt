# GLOBAL EXECUTION RULES

整个 R1 必须遵守：

1. **不重新建立已经存在的 method calculation authority。**
    
2. **不重新建立 FDR / FCR / FAR / HFP / PFR。**
    
3. **不重新建立 Relationship W0–W8。**
    
4. **不删除已冻结 Profile runtime。**
    
5. **Profile 从产品降级，不代表删除 Profile evidence capability。**
    
6. **Method 不成为 Reality Fact。**
    
7. **Assessment 不成为 Reality Fact。**
    
8. **Market Data 不直接成为投资建议。**
    
9. **Cross-method convergence 不等于真相。**
    
10. **Current data 必须保留 source / time / freshness / provenance。**
    
11. **Unknown 不得自动补值。**
    
12. **Customer Reality persistence 必须明确 consent。**
    
13. **没有 customer-visible outcome 的新 contract 不得无限扩展。**
    
14. 每个新 runtime 必须最终回答：
    

```
Who consumes this?
Where does the customer see it?
What action can it support?
What does it NOT authorize?
```

15. 每个 phase 必须具备：
    

```
Contract
→ Runtime
→ Projection
→ Customer Surface
→ Machine Gate
→ Human Gate
→ Cutover
```
