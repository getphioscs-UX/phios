# HD-PRO-R3-W13｜Semantic Precedence + Dedup Engine

W13 does not create new Human Design meanings. It coordinates already admitted atomic and composed claims so the customer reading has one primary explanation for one semantic cluster while preserving the lower-level claims as evidence.

The deterministic precedence is:

`Chart-level composition > Authority composition > Profile composition > Channel composition > Definition composition > Center meaning > Gate detail > Advanced Variable modifier`.

A claim can enter the same dedup cluster through an explicit semantic cluster id, the same reality implication, or the same evidence set. The highest-precedence claim becomes the primary explanation. Lower-precedence claims are not deleted: their source refs and subject refs remain available as supporting evidence for a later “why this reading” surface.

The engine deliberately does not use an opaque similarity score, does not resolve genuine contradictions by suppressing them, does not let Variable/PHS override the core chart, and does not change R2 customer publication or R3 human-review gates.
