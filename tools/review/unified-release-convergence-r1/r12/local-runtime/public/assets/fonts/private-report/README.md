# Private PDF font

Noto Sans SC, SIL Open Font License 1.1 (see OFL.txt).
Source: https://github.com/google/fonts/tree/main/ofl/notosanssc
Input: NotoSansSC[wght].ttf from the official Google Fonts repository.
The bundled static TrueType instance was produced with fontTools 4.65.0 at wght=400.
It is embedded in private PDFs so Chinese and English remain readable without a network font dependency.
The full static font is embedded: the PDF library's subset output failed visual rendering and is not used.
