# ZWR lunar table executable representation — third-party notice

The embedded 1900–2100 `lunarInfo`-style month/leap table in
`functions/zi-wei-runtime/lunar-calendar-table-v1.js` is derived from the
open-source SolarLunar implementation maintained by yize. PHI OS uses it as
an executable table representation only; the Human-frozen validation authority
for Zi Wei v1 remains the Hong Kong Observatory Gregorian/Lunar conversion table.
