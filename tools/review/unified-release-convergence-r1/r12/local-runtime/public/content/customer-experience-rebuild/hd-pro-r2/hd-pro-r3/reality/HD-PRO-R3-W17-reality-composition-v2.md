# HD-PRO-R3-W17｜Reality Composition v2

Reality questions are generated from semantic findings, not generic trait prompts. Eight categories are supported: Decision, Engagement, Work/Energy, Relationship, Openness/Pressure, Environment, Role and Contradiction. Customer responses use CONFIRMS / PARTIALLY_CONFIRMS / CONTRADICTS / NOT_OBSERVED / CONTEXT_DEPENDENT and remain reality evidence rather than chart facts.
