# WPR-5V｜Post-Freeze Five-Volume Web Projection Successor

Baseline: `1cbc50f7590759774944a577d3082c13ef59c40b`

WPR-5V is a post-freeze successor projection, not WPR v2. WPR v1 remains frozen at its 38-record predecessor authority. The five-volume successor contains 40 `LIMITED_PRODUCTION` records: existing Book III/IV detail records are rebound to the current Volume III/IV identities and the Volume V locale pair is added, producing five identity-aligned Book detail pairs without rewriting the 38-record predecessor.

Canonical public order:

1. Volume I · Reality Formation · P1–P4
2. Volume II · Reality Runtime · P5–P7
3. Volume III · Reality Continuity · P8–P9
4. Volume IV · Reality Civilization · P10–P12
5. Volume V · Reality Navigation · P13–P15

Publication context is resolved from governed Part Authority / Publication Ownership into the Current Book Registry. Explicit accepted node rehome overrides are represented in the projection registry without changing Canonical Node identity. The browser runtime never parses the `B` prefix of a node code to infer Book or Volume.

Canonical routes are the five semantic `/books/...` routes. `/books/reality-maintenance` is retained only as a non-canonical `308` compatibility redirect to `/books/reality-continuity`; numeric `/book-3`, `/book-4`, `/book-5` routes are not canonical authority.

Public discovery grows from the frozen W25 predecessor's 16 routes to a 17-route successor sitemap. WPR-W25 and WPR-W30 use versioned post-freeze checker reconciliation v2 so the original W25/W30 authority remains historical and unchanged.

The old BOOK-W1E candidate remains unactivated historical evidence. `book-w1e-wpr5v-web-projection-successor-reconciliation-v1.json` authorizes only this WPR-5V web successor; it does not activate BOOK-W1E, Canonical Node authority, active Blueprint authority, CPR authority, or WPR v2.

BOOK-5's cover object is declared by the Current Book Registry, but the predecessor Public Asset Registry has no `BOOK-5-HARDCOVER` record. WPR-5V therefore does not invent asset authority: the Book V public record carries no governed asset reference and the card renderer fails safely to its visual fallback until an upstream public-asset record exists.
