# PJA-W2F-C0B｜Historical PJA Registry Migration

## Migration boundary

Historical PJA freeze scripts may preserve the state created by their own stage,
but may not permanently prohibit later PKR-owned Registry population.

The valid invariants are:

```text
Population ownership = PKR
Publication ownership = PJA
Registry presence does not create Article production
Localized identity does not create publication
Historical stage preservation does not freeze future Registry scale
```
