Baseline: `058bad17580a3a2494ade2268104c5cab2428782`

## W3 — Foundation
Adds one projection-only manifest and one client renderer. It does not create a second visual authority or historical source.

Visual posters are orientation surfaces only. Registry-driven HTML remains authoritative.

## W4 — Seven-layer binding
- L2 Timeline poster
- L3 Case Registry poster
- L4 Comparison Families poster
- L5 fifteen World Snapshot poster slots
- L6 Long-Duration Trajectories poster
- L7 Transition Windows poster
- L8 Reversal & Loss poster

The active World Snapshot selects its matching poster through the existing Atlas State. Other layers use one overview poster while their existing HTML controls drive all state changes.

## Fail-closed behavior
The aligned repository does not contain these poster files locally and does not yet register them in the existing seven-volume visual registry. Therefore every Atlas poster binding is explicitly `UNVERIFIED_ATLAS_POSTER`.

If a remote object is absent or fails to load, the poster area becomes a clear fallback message while the full structured Atlas continues to work. No broken-image UI and no invented geometry.

## Interaction
Poster viewer supports lazy loading, async decode, full-screen dialog, keyboard-close behavior through native dialog semantics, desktop pan/scroll, and mobile full-screen viewing.

Exact historical hotspots are deliberately not inferred from generated poster pixels. Selection/highlight remains state-driven through the structured Timeline / Case / Comparison / Snapshot / Trajectory / Transition / Loss controls.
