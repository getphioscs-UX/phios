# KPR-W0｜Compatibility Research Boundary

## Decision

PJA remains the only authoritative Canonical Article production, review and publication pipeline.

KPR is an experimental, post-review research branch. It is not a production runtime, Registry authority, Article dependency, publication gate or deployment dependency.

## Frozen production path

```text
Canonical Node Registry
→ Production Brief
→ Canonical Article Package
→ Validate
→ Import Dry-run
→ Import Apply
→ Human Review
→ Human Approval
→ Publication Freeze
→ Localization
→ Git / Cloudflare Deployment
→ Production Acceptance
```

## Prohibited KPR effects

KPR must not:

- change the Canonical Node identity model;
- change Article, Claim, Source, Review or Production Package schemas;
- introduce Meaning Freeze or Projection Readiness before Article production;
- create approval, publication-ready or published state;
- become a dependency of PJA checks, production commands, public pages, Runtime or Professional Workspace;
- create authoritative Meaning, Formation Rule, Meaning Relationship or Projection Registries before a later explicit decision based on demonstrated reuse value.

## Current repository decision

The experimental KMR-W0 and KMR-W1 Registry, Schema and inventory artifacts are removed. Their existence had not changed public pages or PJA contracts, but retaining them would imply a second governance system.

Future knowledge reuse experiments must use isolated fixtures or research output under a non-authoritative KPR scope. No KPR artifact may be treated as production truth.
