Gate Base Meaning × Line Modifier × Planetary Driver Role × Personality/Design → Semantic Tags → admitted Runtime Owner。

64 个 Gate 基础槽位、6 个 Line 修饰槽位、12 个 Driver 角色及两种快照角色；没有建立 384 个 direct owner mappings。只有具备明确来源和人工内容绑定的组合规则可输出个人意义，当前未获准的组合仍为 UNKNOWN。
