## 改写原则

正文应当解释这张命盘，而不是教客户如何核实报告。每章从本盘的干支、十神、透藏或合冲关系出发，展开该领域的含义；建议应当从解读自然形成。专业边界集中放在附录，正文只保留必要的局部说明。不得以改善文风为理由，补出强弱、用神、合化、真实经历或具体历法结论。

原章节底图、底色和既有打印排版资产没有改动。此次 PDF 是独立文字审阅稿，未将待验收正文装配进原三十八页成品。三个案例仍是结构测试案例，不具有已核实的客户出生身份。
