# 10｜REALITY SUMMARY

After QUICK/GUIDED/DEEP intake, generate a structured customer-readable summary before method execution.

Example form:

```
We currently understand:

You have experienced a significant work-environment change over the last three months.

Your main concern is not income but sustained energy and loss of direction.

You want to understand whether this is:
• temporary adaptation,
• structural mismatch,
• or a current phase of change.

Current supporting evidence:
• energy has decreased,
• motivation has decreased.

Counter-evidence:
• work performance remains stable.
```

Buttons:

```
Yes, this is accurate
是的，这很准确

Edit
修改

Something is missing
还少了什么
```

Only confirmed summary may be promoted into governed Current Reality evidence.

Do not treat an LLM-generated summary as evidence before customer confirmation.
