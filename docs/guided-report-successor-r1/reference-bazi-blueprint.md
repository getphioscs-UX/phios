# BAZI-04｜如何阅读这份报告
## HOW TO READ THIS REPORT

### 页面角色
`HOW_TO_READ_REPORT`

### 固定标题
**如何阅读这份八字报告？**  
**HOW TO READ THIS BAZI REPORT**

### 固定副标题
**把计算、解释、现实证据与未知分开，你会更容易知道哪些内容值得相信、比较与继续观察。**  
**Separate calculation, interpretation, current evidence, and open questions so you can see what is established, what is conditional, and what still needs observation.**

### 固定中文正文

这份报告不会把所有内容放在同一个确定性层级。八字中有些内容来自明确计算，例如四柱、干支、五行关系与已经确定的时间位置；有些内容属于对这些结构的解释，需要结合条件与整体关系理解；另一些内容只有在客户提供当前生活、工作、关系、资源或环境资料后，才可以进一步与现实比较。

因此，每一页都会尽量区分四种状态：**已计算、解释、当前证据、仍待观察**。当一个结论来自方法结构，我们会说明它来自哪里；当它需要现实条件才能成立，我们会保留条件；当现有资料不足，我们不会为了让报告显得完整而补成确定答案。

阅读这份报告时，不需要把每一句都当作结论。更有价值的方式，是观察哪些结构与你的现实相符，哪些只在特定阶段出现，哪些值得继续验证，以及哪些地方暂时仍然开放。

### Fixed English Copy

Not every part of this report has the same level of certainty. Some information comes directly from the BaZi calculation, such as the Four Pillars, Stem–Branch structure, Five Element relationships, and admitted timing positions. Other content is interpretive and must be understood in relation to the wider structure and its conditions. Some comparisons only become possible when current information about work, relationships, resources, environment, or lived circumstances is available.

For that reason, the report distinguishes four states: **Calculated, Interpreted, Current Evidence, and Open**. When a statement comes from the method structure, its source should remain traceable. When an interpretation depends on conditions, those conditions should remain visible. When evidence is insufficient, the report should not convert uncertainty into a definitive claim.

You do not need to treat every sentence as a conclusion. The more useful approach is to notice what matches your Reality, what appears only under particular conditions, what deserves further observation, and what still remains open.
