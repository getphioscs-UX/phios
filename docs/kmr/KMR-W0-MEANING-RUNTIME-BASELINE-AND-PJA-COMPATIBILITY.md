# KMR-W0｜Meaning Runtime Baseline and PJA Compatibility

## Purpose

KMR-W0 establishes an additive Meaning Runtime boundary without replacing the existing Canonical Node or PJA Article production system.

## Layering

```text
Canonical Node
├── Canonical Meaning Record
├── Formation Rules
└── Projection Records
```

PJA remains the governed website-article production pipeline. KMR does not publish, approve, review, write Runtime data, or create Professional authority.

## Baseline contracts

- Canonical Meaning Record
- Formation Rule
- Projection Record
- Meaning Relationship
- KMR-W0 Boundary Policy

All four registries are intentionally empty at W0. Book I inventory and candidate extraction belong to later stages.

## Compatibility guarantees

- Existing node codes remain unchanged.
- Existing Article, Claim, Source and Review schemas remain unchanged.
- Existing PJA readiness and production packages remain unchanged.
- Existing public pages do not read Meaning Runtime registries.
- Meaning records are deny-by-default for public use.
