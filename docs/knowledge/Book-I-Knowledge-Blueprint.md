# KH-W3.5G｜Book I Knowledge Blueprint

## 1. 本轮目的

本 Blueprint 不把书籍目录复制成文章清单，也不要求立即制作整本书的公开内容。它只冻结第一册的知识骨架，使书籍、文章、影片、图像、Atlas 与 Professional Workspace 将来可以引用同一组知识身份。

第一册仍是完整理论的主要载体；Knowledge Hub 文章只承担入口、解释、搜索与服务前置理解，不取代书籍。

## 2. 为什么需要这份 Blueprint

没有 Blueprint 时，同一个概念可能在不同部、不同文章、影片与报告中被重复生产，并逐渐形成彼此不一致的版本。Blueprint 的作用不是增加管理工作，而是提前回答三个问题：一个机制只维护几次、从哪里引用，以及现在是否值得生产。

因此，Blueprint 的实际价值体现在内容开始扩展之后，而不是今天立即显示在公开网站上。当前只需要维护一份地图，不需要维护数十个页面。

## 3. 冻结结构

```text
Book I
↓
Part
↓
Canonical Knowledge Node
↓
Article / Figure / Video / Atlas / Professional Reference
```

Supporting Question 与 Search Alias 暂不纳入本轮扩展。它们可以保留在既有 Registry，但不作为 Book I Blueprint 的生产单位。

## 4. 整体数量

- 序部既有正式节点：13
- 第一部至第五部新增规划节点：65
- 第一册总规划节点：78
- 单次活跃生产上限：8
- 立即生产：只启动首轮 8 个节点

节点数量不是页面数量，也不是章节标题数量。多个相邻标题在解释同一形成链时，会被合并为一个机制节点。

## 6. 与平台的关系

第一部至第三部主要支持 Knowledge Hub、Reality Atlas 与 Reality Journey 的基础语言；第四部与第五部主要支持 Human Runtime、Professional Reading、报告解释与客户前置教育。连接只表示未来可以引用，不表示现在必须开发功能。

## 7. 边界

- 不修改书籍正文。
- 不修改 Reality Journey Runtime。
- 不建立公开页面。
- 不自动生成英文文章。
- 不把人类图、占星或其他读取体系当成配置形成原因。
- 不把知识节点转成诊断、治疗、预测或强制建议。

## 8. 下一阶段建议

KH-W3.5G 完成后，不建议继续扩展 Registry 结构。下一步应进入首轮 8 个节点的 Production Brief，或者暂时冻结 Knowledge Hub，优先继续 Professional Workspace。
