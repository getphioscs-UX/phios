# PKR Scope & Production Economy Policy

Contract: `PHI-OS-PKR-Scope-and-Production-Economy-v1.0.0`

## PKR 管理范围

PKR 管理：

- Collection、Theme 与 Knowledge Node 的身份
- Canonical Question、Core Insight 与知识边界
- 来源、版本与书籍引用
- 中文与英文内容关系
- Asset Requirement 与生产等级
- 节点学习关系
- 发布状态
- Service Reference
- ChatGPT Production Brief

PKR 不管理：

- 网页视觉、Header、Footer、断点与按钮
- 订单、付款、价格与客户身份
- 个案报告、Professional Notes 与服务判断
- Reality Journey 运行状态
- 预约、咨询记录或客户隐私资料

## Production Economy Principles

### PKR-PE-01｜Service-first

知识生产不得长期压过 Professional Services 的开发、成交与交付。

### PKR-PE-02｜Article-first

书籍知识节点默认以 `canonical_article` 为主要资产。

### PKR-PE-03｜One Canonical Asset

每个节点只设一个主要知识资产，其他媒体均为衍生资产。

### PKR-PE-04｜Chinese Canonical

中文负责理论母本、核心判断、知识边界与版本变更。

### PKR-PE-05｜English Localized

英文必须保留同一 Knowledge Core，不得独立增加核心理论或改变确定程度。

### PKR-PE-06｜No Duplicate Creation

文章、视频、音频与媒体贴文不得分别从零生产。

### PKR-PE-07｜Master Media Post Default

每篇正式文章默认产生一个中文 Master Media Post；英文文章完成后产生一个英文 Master Media Post。

### PKR-PE-08｜Video by Selection

只有品牌核心、高公众共鸣、高服务解释价值、已有阅读需求或适合视觉说明的节点才扩展视频。

### PKR-PE-09｜Audio by Extraction

Audio 默认从文章朗读或视频音轨产生，不建立独立内容线。

### PKR-PE-10｜Demand-led Expansion

只有真实阅读、客户问题、服务引用、课程需求或视觉表达需求出现时，才增加更多资产。

### PKR-PE-11｜Service Explanation Saving

优先制作能够减少购买前、报告阅读与咨询过程中重复解释的节点。

### PKR-PE-12｜No Forced Conversion

公共知识允许自然连接相关服务，但不得把知识正文写成强制购买入口。

### PKR-PE-13｜Requirement-based Completion

只有标记为 `required` 的资产未完成时，节点才是不完整；`optional` 与 `not_required` 不构成缺陷。

### PKR-PE-14｜Batch Localization

Tier A 与 Tier B 可按每四个中文节点进行一次英文 Localization Batch；Tier C 同步完成中英文。

### PKR-PE-15｜Single Theory Review

主要理论审核发生在中文 Canonical Content；英文审核集中于术语、语义一致、自然表达与边界保持。

## Production Tiers

### Tier A｜Essential Article

必备：Knowledge Core、中文文章、中文 Master Media Post、来源与边界。

英文进入批次本地化；视频、音频不要求。

### Tier B｜Public Resonance

必备：Knowledge Core、中英文文章、中英文 Master Media Post。

短视频与简单图示可选；允许中文先发布、英文后补。

### Tier C｜Brand Foundation

必备：Knowledge Core、中英文文章、中英文 Master Media Post、Figure Brief、短视频脚本与长视频脚本。

实际成片可在排期后制作；Audio 为衍生可选项。
