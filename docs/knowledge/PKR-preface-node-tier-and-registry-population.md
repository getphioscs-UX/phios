Contract: `PHI-OS-PKR-Preface-Registry-v1.0.1`

Status: Frozen for content production planning.

## Scope

This milestone populates the Preface collection with 36 language-neutral Knowledge Nodes, 10 Themes, 11 source-section references, bilingual display questions, production tiers, queues, value metadata, asset requirements, and initial learning paths.

It does not create public pages, article bodies, JavaScript loaders, service prices, customer data, orders, payments, or Professional Workspace records.

## Tier distribution

- Tier C: 6 brand-foundation nodes.
- Tier B: 10 public-resonance nodes.
- Tier A: 20 essential explanatory nodes.

Tier determines required asset depth. Production Queue determines when a node is produced. Tier and Queue are intentionally separate.

## Launch rule

Launch is not permission to publish. It only marks the initial production queue. Every localized asset must still pass the PKR review and publication checklist.

## Registry authority

`nodes.json` is authoritative for node identity, tier, queue, value, relationships, source references, and asset requirements. `localized-content.json` is authoritative for public questions and locale-specific production states.
