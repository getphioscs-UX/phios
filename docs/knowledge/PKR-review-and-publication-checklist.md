# PKR Review & Publication Checklist

## Knowledge Core Review

- [ ] Node Code 与 Canonical Question 一致
- [ ] Source Reference 完整
- [ ] Core Insight 单一且清楚
- [ ] Required Claims 均来自来源
- [ ] Mechanism Sequence 合理
- [ ] Knowledge Boundary 可见
- [ ] Prohibited Claims 已建立
- [ ] 未将未知内容自动补齐
- [ ] Service Use 仅为解释支持

## Chinese Article Review

- [ ] 文章回答指定问题
- [ ] 没有偏离 Knowledge Core
- [ ] 没有大段复制付费书籍
- [ ] 没有个人诊断
- [ ] 没有保证结果
- [ ] 没有硬性销售
- [ ] 作者框架与研究事实区分清楚
- [ ] 中文自然，无明显翻译腔
- [ ] Boundary 与 Next Node 明确

## English Localization Review

- [ ] Core Insight 与中文一致
- [ ] Required Claims 无增加或遗漏
- [ ] Mechanism Sequence 一致
- [ ] 确定程度一致
- [ ] Terminology 一致
- [ ] 英文自然，不机械逐字翻译
- [ ] Knowledge Boundary 完整
- [ ] 无新增理论

## Publication Gate

- [ ] registryStatus = frozen
- [ ] required Assets 已完成
- [ ] contentStatus = content_reviewed
- [ ] 对应语言 reviewStatus = approved
- [ ] slug 唯一
- [ ] SEO metadata 完整
- [ ] Related Node 存在
- [ ] Service Link 符合边界
