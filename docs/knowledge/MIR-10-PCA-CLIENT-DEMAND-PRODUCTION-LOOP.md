# MIR-10 | PCA Client Demand -> Knowledge Production Loop

MIR-10 is an additive successor to the frozen PCA-W0-W8 demand loop. It does not replace Canonical Knowledge, KPP, PJA, CAR, Interpretation, Method, Reading, BFA, or Publication authority.

## Current flow

`KAP / Guided Reading / RJX / Search / Knowledge Retrieval -> de-identified aggregate demand -> cluster -> advisory priority -> KPP -> candidate-only PJA/CAR handoff -> external Human Review -> existing publication authority -> published coverage feedback`.

Demand can change planning evidence and future production priority. Demand cannot create truth. Popularity never becomes a Canonical Claim, Meaning, Method rule, Interpretation rule, Figure authority, Human approval, or Publication.

No production telemetry is fabricated by this work. The successor registries remain empty until real aggregate telemetry exists. The checkers use non-production fixtures only.
