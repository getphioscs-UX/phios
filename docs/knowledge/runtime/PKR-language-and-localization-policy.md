# PKR Language & Localization Policy

## 1. Canonical Language

```text
zh-Hans
```

中文负责正式理论表达、论证顺序、知识边界与内容版本。

## 2. Required Public Languages

```text
zh-Hans
en
```

英文是正式公开语言，但不是独立理论分支。

## 3. Localization Pipeline

```text
Knowledge Core
↓
Chinese Canonical Article
↓
Chinese Content Review
↓
English Localization
↓
Terminology Review
↓
Semantic Parity Review
↓
Publication
```

## 4. 英文允许调整

- 句子结构
- 段落节奏
- 标题自然度
- 中文特有表达的说明方式
- 不改变理论的连接语与例子表达

## 5. 英文禁止调整

- 增加新的核心理论
- 删除重要知识边界
- 把推论改写成确定事实
- 引入未经来源支持的结论
- 把 PHI OS 改写成治疗、预测、宗教或保证结果的体系

## 6. 发布策略

Tier C 中英文同步发布。

Tier A 与 Tier B 可中文先发布；英文进入批次本地化。建议每四个中文节点形成一个英文批次。
