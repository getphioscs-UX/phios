# PKR Service Reference Policy

## 1. 目的

Service Reference 用于指出某个公共知识节点如何帮助购买前理解、服务准备、报告阅读与后续咨询。

## 2. 允许保存

- serviceCode
- relatedNodeCodes
- prePurchase
- servicePreparation
- reportExplanation
- professionalFollowUp
- buyerEducationValue
- explanationSavingValue
- reportSupportValue

## 3. 禁止保存

- customerId
- orderId
- paymentStatus
- price
- Professional Notes
- 个案判断
- 客户隐私资料
- 报告正文

## 4. 公共呈现

只有在内容确实相关时，页面才可显示非强制式服务连接。不得以知识缺失制造购买压力。
