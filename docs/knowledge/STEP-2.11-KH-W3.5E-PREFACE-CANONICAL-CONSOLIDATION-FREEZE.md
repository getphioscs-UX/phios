## Frozen consolidation

The original 36 Preface Questions are preserved through one non-duplicative
classification:

```text
36 Preface Questions
↓

```

No question identity was deleted. The 13 Canonical Nodes each retain exactly
one canonical representative from the original inventory; the remaining 23
question identities each become one Supporting Question linked to exactly one
Canonical Node.

## Canonical granularity

The following rules are frozen:

- one page does not equal one node;
- one heading does not equal one node;
- one question does not equal one article; and
- only an independent reusable mechanism may become a Canonical Node.

A Canonical Node must sustain an independent mechanism, a distinct knowledge
boundary and long-term bilingual maintenance. A Supporting Question inherits
the knowledge boundary of its Canonical Node, does not require an independent
article and cannot create a second Knowledge Core.

## Relationship integrity

All 36 legacy question identities are unique and classified once. All 13
Canonical Node codes and 23 Supporting Question codes are unique. Every
Supporting Question resolves to one valid Canonical Node, and each reference
is present in both the Node and Supporting Question records. Orphan,
unclassified and duplicate mappings are prohibited.
