## W12｜Contradiction / Counter-Evidence Resolution

W12 preserves rather than erases disagreement. Explicit counter-evidence produces `COUNTERBALANCED`; multiple unresolved pattern candidates produce `ALTERNATIVES_OPEN`; unresolved school-specific views remain `SCHOOL_VIEW_OPEN`; unknown prerequisites bound a unit instead of being converted to negative evidence. A cross-layer combination whose transformation has not been established is `QUALIFIED`, not failed and not transformed by assumption.

The resolver cannot delete findings, choose a winning school, manufacture a strong/weak verdict, assign a pattern winner, select useful-god/tiaohou elements without their prerequisites, or create event predictions.

## W13｜Semantic Deduplication

W13 assigns one full-explanation owner per semantic cluster before Reading IR construction. Exact semantic repeats become references to the primary owner. A second unit may remain a context derivative only when it carries new finding/evidence/authority/unknown/counter-evidence information. School identity and temporal context are part of the dedup key, so different schools and different time windows are never collapsed into one primary explanation.

The fixture naturally contains seven different semantic clusters, so it has seven primary owners and no suppressed full explanation. The checker also injects duplicate test units to prove exact duplicates collapse to one primary while additional information remains a context derivative.
