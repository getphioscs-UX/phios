# PVP-R1-VIS-W8 | Profile Visual MVP

W8 implements the first customer-rendered Profile visual set from the frozen W7 projection IR: PFIG-001, PFIG-003, PFIG-005 and PFIG-009.

The renderer is projection-only. Profile/PPR remains the truth owner. Missing or unmappable evidence renders an explicit unresolved state and is never synthesized into a visual result.

Customer surface integration is additive: the existing Profile result summary, source legend, signals, career results and boundaries remain in place. The API now attaches the governed `visualProjection` generated from the published Profile view; the customer renderer consumes that IR without recalculating Profile meaning.

PFIG-002, PFIG-004 and PFIG-006–008 remain authority-admitted but are not claimed as W8 MVP renderers. W9 remains the next Profile product gate.
