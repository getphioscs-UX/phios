# Profile/PPR Customer Output Successor

Baseline: `d0e312329077944340d88cf57be883457217e0f2`.

This successor resolves the W6 authority gap at the existing Profile/PPR owner. Resolution is deliberately not equivalent to inventing every generic Profile field. Each requested field receives one of three owner decisions: an admitted provenance-preserving customer field, a narrower evidence-only projection, or an explicit `NOT_ADMITTED` generic semantic field.

## Newly admitted projection-safe fields

`profileOverview` is a container of available governed sources and sections, not a synthesized personality verdict. `sourceScopedDimensions` preserves each source's dimensions and values without cross-instrument normalization. `tensionSignals`, `contextEvidence`, `contradictions`, and `realityQuestions` expose only already-admitted evidence. Existing relationship evidence and career-interest outputs remain available under their original semantics.

## Explicitly not admitted

Generic Strength Patterns, Decision Style, individual Relationship Style, generic Work Style, Stress Pattern, objective Environment Fit, universal Core Dimensions, and any universal Profile score remain non-authoritative. This is a completed owner decision, not an unresolved PVP gap.

## Cross-source visual vocabulary

Profile/PPR authorizes only the conservative direct mappings `SOURCE_ALIGNED → CONVERGES`, `SOURCE_CONTRADICTION → DIVERGES`, and `OPEN → UNKNOWN`. `CONTEXT_DEPENDENT` requires explicit context evidence tied to the perspective and may not be inferred from `SOURCE_COMPLEMENTARY` or `SOURCE_TENSION` alone.

## Gate consequence

W6 authority ambiguity is closed and PVP-R1-VIS-W7 may now build a projection IR from the admitted subset. This does **not** admit every PFIG: universal radar, generic Strength/Cost, and Decision Map remain blocked until their Profile/PPR semantics are separately established.
