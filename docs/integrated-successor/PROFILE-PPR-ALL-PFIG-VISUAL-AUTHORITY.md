# Profile/PPR All-PFIG Visual Authority Admission

Baseline: `3eea58913bb7188089a2912ba6de1a0a5bf91bf0` (`PVP-W6`).

This successor closes the semantic blockers discovered by PVP-R1-VIS-W6 **at the Profile/PPR owner layer**. It does not let PVP invent Profile truth.

## What changed

All nine PFIG IDs are now semantically allowed because each visual consumes a governed output type:

- PFIG-001 and PFIG-002 use source-aware dimensions / visual lenses and never create a master score.
- PFIG-003 uses explicit customer-confirmed `HELPS_ME` / `COSTS_ME` evidence or already admitted tension evidence. High/low scores are not relabeled as strengths/weaknesses.
- PFIG-004 uses explicit context observations and Current Reality.
- PFIG-005 uses a complete Profile/PPR-owned mapping into `CONVERGES / CONTEXT_DEPENDENT / DIVERGES / UNKNOWN`, while preserving the native group.
- PFIG-006 is work-interest + observed work-expression, never job fit.
- PFIG-007 is relationship evidence + observation targets, never compatibility.
- PFIG-008 is decision evidence, never a fixed universal decision type.
- PFIG-009 remains a Reality bridge from admitted Profile evidence.

## Important distinction

`ALL_PFIGS_AUTHORITY_ALLOWED = true` means the semantic/authority blocker is closed. It does **not** mean W7 Projection IR or W8 renderer implementation is already complete.
