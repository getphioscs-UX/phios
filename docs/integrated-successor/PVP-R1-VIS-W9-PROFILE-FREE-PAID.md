# PVP-R1-VIS-W9｜Profile Free / Paid

Defines three customer depth states: **Free Snapshot**, **Deep Profile**, and **Reality Profile**.

W9 does not create a price, checkout route, membership entitlement, or new Profile truth. The current Profile API therefore resolves to `FREE_SNAPSHOT`. Paid depth requires a future trusted server-side entitlement from the existing commerce/PAI owner; request body and query parameters cannot self-upgrade access.

Free Snapshot projects a deliberately reduced form of PFIG-001/003/005/009. Deep Profile and Reality Profile are visible value previews only until commerce authority and the remaining deferred renderers are admitted.
