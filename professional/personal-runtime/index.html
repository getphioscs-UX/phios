What it is

它是什么What it is

一个基于出生资料或现有 chart 的结构化 interpretive system，用于 secondary lens 阅读。A structured interpretive system based on birth data or an existing chart, used as a secondary lens.

How PHI OS uses it

PHI OS 如何使用它How PHI OS uses it

系统中的概念必须先被改写进入 PHI OS Runtime language，再由人类专业判断进行 review，不直接照搬为 authority。Concepts are rewritten into PHI OS Runtime language and then reviewed by a human professional instead of being copied into authority directly.

What it cannot do

它不能做什么What it cannot establish

它不能证明事实、病因、诊断、必须行动、命运结论或未来保证。It cannot establish facts, causes, diagnosis, required action, destiny or guaranteed future outcomes.

Inputs

需要的资料Required materials

准确的出生日期、时间、地点、时区，或现有 chart 文件。缺少准确输入会直接影响结果边界。Accurate birth date, time, place, timezone, or an existing chart file. Input quality directly affects the boundary of the output.

Boundary

解释与证据必须分开Interpretation and evidence remain separate

Personal Runtime 的解释必须和现实中观察到、报告到与证据化的内容保持分层。Personal Runtime interpretation stays distinct from what is observed, reported and evidenced in reality.
